把 Codex、Claude Code 的对话和项目看板放在一起。查看进展、阅读成果、回复消息，需要你决定时及时处理。

![Agbrio 项目看板](docs/assets/boards-project-current.png)

## 离开电脑，也能接着工作

- **跟进对话**：查看执行状态和最新回复，在手机上回复原对话。
- **处理问题**：回答支持的提问与选项，查看子对话的工作状态。
- **转交成果**：选择有用的内容，确认目标后转给另一条对话。
- **直接读文件**：在对话里打开 Markdown、图片、代码、JSON 和 CSV。

## 让 Agent 把成果整理成看板

项目进展、方案对比、资料报告，都可以变成手机上的一个页面。打开 **看板**（已有看板时点 **创建看板**），选一个示例，把指令发给电脑上的 Agent。创建完成后，看板会出现在 Agbrio，跟随项目文件更新。

![看板示例与 Agent 创建入口](docs/assets/boards-guide-current.png)

## 开始使用

1. **[下载 Windows 版](https://github.com/geoffrey1111/agbrio/releases/latest)**，连接正在使用的 Agent。
2. **选择对话，或创建看板**，从手头的项目开始。
3. **在 设置 → 设备 配对手机**，使用托管兑换码或自己的 HTTPS 连接。

手机访问时，电脑和 Agbrio 需要保持在线。
