# Agbrio

**Agent Bridge — connect your agent conversations.**

Agbrio connects existing agent conversations so you can read results, choose
handoff content and attachments, and confirm a handoff from your phone.

This repository is being prepared for open-source release. Source export,
licensing, installers and general self-hosted onboarding are still in progress.

## Direction

- A desktop Host on your own computer, with an iPhone-friendly PWA.
- Explicit confirmation before handing work between two conversations.
- Mobile notifications and replies to the original conversation.
- Your own remote-access provider: Cloudflare Tunnel, Tailscale Funnel/Serve,
  or an existing HTTPS reverse proxy.
- A setup instruction you can give to your own coding agent.

The personal implementation currently uses Windows and Codex. Provider-independent
onboarding, macOS and additional agents require separate verification. These are
planned capabilities, not current release guarantees.

No hosted multi-user service or public download is available yet.
