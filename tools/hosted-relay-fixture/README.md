# Isolated hosted transport regression

This is an opt-in project integration test. It never deploys a service or uses a real tenant, activation code, trial quota, provider credential or model. It creates a loopback-only TLS service on port 443, runs the unchanged repository Worker in Miniflare with ephemeral Durable Objects, seeds synthetic codes and trial addresses, and starts the exact compiled Rust lib test executable with a private HOME/profile. It drives the production Rust redemption/trial/renewal/configuration, staged Node connector, pairing, and PWA through real TLS/WSS. The native app-server peer is synthetic; one repeated SEND must yield exactly one native request. This is not evidence of a real provider, physical phone or external Mac test.

IOPlatformUUID is read independently by the explicit Mac native identity test and by the trial fixture; only the existing product hash reaches the test service. Missing/invalid identity fails; there is no random fallback. Nothing adds a root certificate to the OS or a user browser. Rust and Node trust only this one ephemeral fixture certificate; the disposable project-test Chromium accepts only its SPKI. Neither production client TLS nor service billing/eligibility rules are changed.

Pinned Miniflare 4.20260730.0 supports compatibility date 2026-08-06, while deployment declares 2026-10-01. The fixture explicitly uses the emulator-supported date; the deployed Worker/config remain untouched. This is a known emulator/production runtime gap. Existing service regression tests also run unchanged.

The Mac source workflow builds the exact test executable, selects it from Cargo JSON, uses the same staged ARM64 Node as the package, and requires positive identity/transport markers (zero tests do not pass). Dependencies here are test-only and not bundled. Temporary certificate/key, codes, storage, browser context and owned processes are removed on success or failure. Windows local developers may supply AGBRIO_FIXTURE_OPENSSL to their existing openssl executable; Mac CI uses /usr/bin/openssl. Do not run concurrently with another service on loopback 443.

On GitHub Mac runners, only the disposable loopback-443 fixture service uses sudo -n when explicitly opted in by AGBRIO_FIXTURE_PRIVILEGED_SERVICE=1. The orchestrator asserts its own non-root UID, and the native test Host independently asserts non-root. Node connector and project-test Chromium inherit that ordinary user. The listener reads only ephemeral test configuration, terminates on parent pipe EOF/deadline and removes its own root-owned temporary runtime. No installed helper, system policy, trust-store or product privilege change is involved; Windows/local defaults do not use sudo.
