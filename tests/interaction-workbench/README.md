# Agbrio 设置操作树

桌面左侧是分类目录，右侧是一页连续设置。手机把同一目录放在标题下，支持横向滑动；只显示本设备可用的能力。目录点击后把焦点移到段落标题，继续滚动时自动高亮所在分类。

| 分类 | 直接展示或操作 | 需要展开或进入独立流程 |
| --- | --- | --- |
| 概览 | 电脑、Agent、手机和版本状态；Codex / Claude Code 用量 | 管理和检查更新跳到对应段落；配对新手机打开原对话框 |
| 连接 | Codex 接入、Pi 子任务及其工作范围、AI 助手与授权 | 连接状态诊断可展开；授权仍使用现有流程 |
| 手机与设备 | 安装到主屏幕的说明；手机可退出当前登录 | 桌面上的配对与设备管理沿用原对话框 |
| 通知 | 当前设备的提醒渠道与助手通知 | 通知记录是独立列表，返回后回到进入前的页面 |
| 运行保护 | 模型故障自动恢复、资源预警 | 仅在具备这些能力的设备显示 |
| 工作区设置 | 看板来源和管理 | 打开看板、查看或恢复已删除的 Bridge |
| 应用维护 | 语言、版本、更新、缓存、显示诊断、关于 | 更新和清理沿用原有处理和确认 |

从仓库根目录运行以下命令，可导出不依赖开发服务器的单文件预览。预览使用演示数据，不会连接真实账号或发送消息。

```powershell
node tests/interaction-workbench/export-preview.mjs 'D:/path/to/Agbrio-交互预览.html'
```
