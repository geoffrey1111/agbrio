# Optional hosted connection

Self-hosting remains available. In desktop Settings → Devices, an operator-issued
redemption code activates this computer's hosted connection. The activated
instance receives its own connection identity and tenant routing. Pair your
phone to that Host; the code is not a phone login or MCP bearer token. Do not
publish codes or operator credentials in Issues or source archives.

The deployed hosted provider is configured by the distributor/operator; it is
not a universal MCP URL. AI assistant settings show the actual instance resource
used by the existing OAuth route. Each connection still needs owner authorization
and target-client consent. An author's private self-hosted MCP URL must never be
substituted for all users. [Setup](SETUP.md) · [Assistant connection](ASSISTANT_CONNECTION_GUIDE.en.md).
