# Agbrio 0.1.3 — Windows preview

When a task is active, installing an already verified update offers a second confirmation instead of a permanent block. Cancel keeps the current task/app running. Confirm installs only the exact verified version after a consistent data backup, then restarts Agbrio. Sync/receipt capture pauses and Router-owned tasks may be interrupted; shared Codex is not restarted. Uncertain handoffs are not automatically resent. Signature/version/backup/duplicate protections remain.

Includes 0.1.2 read-only Bridge timelines: choose the source only inside Forward, then select blocks, review receiver and confirm. Application 0.1.3 / interface 2026.10.08-23. Windows preview, MIT.

Validation: desktop confirmation cancellation, explicit override, version change, duplicate clicks and backup failure tested; native gate continues to reject missing/stale/unverified candidates even with confirmation. Actual released installer validation and local installation are tracked separately. Physical iPhone and actual Dot connection remain separate acceptance limits. Private demo is not uploaded.
