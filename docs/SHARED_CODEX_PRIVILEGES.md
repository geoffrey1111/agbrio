# 共享 Codex 的管理员启动

设置 → 连接 → Codex Desktop 共享连接，默认勾选“以管理员身份启动共享 Codex”。它同时控制 Codex 窗口和共享执行后台；接入这个后台的对话使用同一套 Windows 执行权限。取消勾选可用普通权限启动。

勾选状态是下次启动的选择，不代表已运行的后台已提权。新版后台会另外显示实际权限。已有任务不会因切换勾选而被重启。

切换现有后台：

1. 等当前任务完成，自行退出共享 Codex。
2. 在 Agbrio 停用共享连接，选择所需权限，再准备共享连接。
3. 打开共享 Codex；按 Windows 提示完成 UAC。准备后台和打开窗口可能分别需要系统确认。

Windows 的系统确认必须由本人完成，聊天里的“允许”不能代替它。没有管理员权限时，可取消勾选后使用普通模式。授权取消后不会自动改用普通权限。

使用同一个 Windows 账号和原来的 Codex 配置、登录及对话记录；不支持为了提权偷偷切到其他用户或复制凭据。这里只控制 Windows 进程权限，不会关闭 Codex 自己的审批或沙箱规则。普通 Codex 的默认启动方式不变。
