# Agbrio0.1.2 — Windows preview

Bridge originals are now read-only timelines. Per-message selection buttons and sticky selected highlights are removed. To forward: open Forward, choose the exact source reply there, select or cancel text blocks, then review the receiving conversation and final text before confirmation. Closing review leaves the original timeline unselected.

Latest-reply status and original-copy controls are independent of a saved transfer draft. Source-specific drafts, attachment loading, exact IDs/hashes, approval freezing and send deduplication remain. Existing shared Codex, hosted connection, paired-device data and language options are retained.

Application0.1.2 / interface2026.10.08-22. Signed build uses the explicit0.1.2 overlay and zlib compression (`-Compression zlib`); source base remains0.1.0. Signatures authenticate updater packages, separately from Windows Authenticode. Private recording demo/resources and operator/code/profile data are not included.

The signed test payload is stored with byte-preserving Git attributes. Physical iPhone and actual Dot owner connection remain separate acceptance limits. Windows preview, MIT.
