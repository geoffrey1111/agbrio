# Project boards and Codex conversations

- Ask your desktop agent for a progress page, comparison or report. Explore examples in Board, copy the instructions and view its work through your existing phone connection.
- Keep multiple boards. Updates preserve reading position and reuse unchanged images.
- Read documents on your phone with a clearer toolbar and typography.
- The Claude Code plugin adds `/agbrio-bridge:codex`: use your authorized Agbrio MCP connection to message a selected Codex conversation and read its reply, without binding a Bridge. First use still requires owner MCP login and consent; waiting is on demand while the assistant is active.
- The GitHub introduction now shows current interfaces with concise setup guidance.

[Get started](https://github.com/geoffrey1111/agbrio/blob/main/docs/START_HERE.md) · [Board guide](https://github.com/geoffrey1111/agbrio/blob/main/docs/BOARDS.md) · [Claude plugin](https://github.com/geoffrey1111/agbrio/tree/main/tools/claude-code-plugin)
