# Shared Codex repair candidate

This is development source pending actual Desktop acceptance. The current stable
release remains0.1.34. Do not enable shared mode merely because a package builds.

The candidate retains a complete signed Codex native cohort, verifies all four
companions and actual JavaScript execution before switching, and rechecks cached
files before a restart. Discovery uses the registered Windows package and exact
process ownership, including packages installed on another drive. Missing or
ambiguous identities fail closed.

An explicit `Codex (Agbrio shared)` Start Menu entry works independently of the
Agbrio window. Official Codex startup remains unchanged. Ordinary Desktop and
active work prevent unsafe switching; idle explicit startup discovers an updated
native cohort without repeating manual configuration. The Windows PowerShell
entry preserves Chinese encoding and shares the application's owner-root mutex.

Shutdown captures exact descendant identities before their root exits, verifies
each identity before cleanup, and retains uncertain recovery evidence. It never
stops all Node processes by name, resends old messages or changes task budgets.
Uninstall removes the shared shortcut only while its target and arguments still
belong to this installation; a replaced entry is preserved.

Verified source layers include large response transport, actual retained native
tool execution and bounded crash recovery, in-flight native-command shutdown,
isolated bilingual launcher guards, shortcut creation/removal, and signed package
readback. The exact draft installer is tested on a disposable Windows runner for
stable-to-candidate upgrade, fictional user-data/cache preservation and uninstall.
Runner results are reported separately; adding this workflow is not a PASS.

Actual installed positive launch, shared Desktop history loading and Desktop
initiated Code Mode remain separate gates. No live user task or credentials are
used by installer validation. A successful webhook or native fixture is not a
whole-client acceptance result.
