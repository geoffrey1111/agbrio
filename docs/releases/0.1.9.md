# Agbrio 0.1.9

This update preserves the original Bridge interactions and the existing assistant
tutorial and project directory fixes.

- Opening or reopening a Bridge, switching roles, or selecting the current role
  positions the reader at the newest reply. Deliberate history reading stays in
  place during polling and late media layout changes.
- An explicitly approved handoff can supplement the recipient's exact running
  Codex turn. It does not pause the Goal, start a replacement turn, or take
  ownership of an external execution. Idle recipients retain ordinary Start.
- Empty reader hints and the Reply to conversation button now use the same
  desktop/phone inset as the title and message content, with a scrollable body
  for short windows. Copy, actions and completed-reply semantics are unchanged.

Exact binding/source/approval checks and at-most-once delivery remain in force.
Missing or mismatched current-turn identity fails before sending; an uncertain
acknowledgement is retained without automatic replay or a Start fallback.

Validation includes frontend/Core/Host regressions, localhost browser fixtures,
and official native Codex with isolated loopback model responses proving
same-turn consumption. Those checks are not physical-phone or user acceptance,
and no production conversations were sent messages for validation.
