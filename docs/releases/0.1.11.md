# Agbrio 0.1.11 — notification and Bridge interaction fixes

- Deleted Bridges stop automatic pushes. Their old standalone watches are paused
  while records and provider tasks remain intact. Explicit Resume is available.
  Pending delivery and final dispatch recheck current notification authority.
- WATCHES sorts by cumulative standalone-list sends, descending. Existing reply
  records supply the counts; no new telemetry is introduced. Order stays fixed
  across polling, an opened chat and return. Leaving the tab/page and returning
  recalculates order. Loading is independent of the recent notification feed.
- The active Bridge side is prominent. A confirmed transfer consumes only its
  exact source result's attention. Older results retain their text and chronology
  without a latest-result dot while another side executes. The receiving side's
  next result restores attention on that side.

Keep original navigation, UI palette, exact-turn supplemental guidance, latest
reader arrival, approvals and at-most-once delivery. UI revision 2026.10.09-28.
Upgrade handles old deleted subscriptions and already-sent exact source records;
a native updater backup is created before applying those local repairs. No
provider task is stopped, no production message replay and no account/grant reset.

Validation uses domain/Host/frontend tests and fictional localhost UI fixtures,
not physical-phone or subjective acceptance.
